# Abdallah Lakhdari — Academic Homepage V4

V4 moves deliberately toward a conventional research-academic homepage rather than an application landing page.

## Positioning
- Primary identity: computer science researcher.
- Breadth is visible across AI, intelligent systems, service/software systems, IoT and digital trust.
- Software engineering remains part of the record without becoming the sole identity.
- Current ambitions are signalled through recent research and projects rather than a manifesto or explicit job-market language.

## Layout
- Standard two-column academic layout on desktop: compact profile sidebar + content column.
- Small 154px portrait.
- News appears near the top, followed by research and selected publications.
- Projects, teaching, recognition/service and background provide evidence for formal hiring criteria without a metrics dashboard.
- Mobile collapses to a compact profile block and simple navigation.

## Deployment
The folder is static HTML/CSS/JS and can be deployed directly to GitHub Pages, Vercel or any static host.
